🏗️ Arquitectura de Despliegue

La aplicación sigue una arquitectura moderna dividida en tres capas principales (Frontend, Backend y Base de Datos) separadas y desplegadas de forma independiente:

1. Frontend (Cliente)

Construido con Vue 3 y empaquetado con Vite. Se despliega como una Single Page Application (SPA) estática en Netlify. Netlify sirve los archivos estáticos HTML/CSS/JS compilados (`dist/`) de forma global mediante CDN y delega el enrutamiento al cliente mediante la regla `_redirects`.

2. Backend (Servidor)

Desarrollado en Node.js usando Express. Expone una API REST y WebSockets (Socket.io). Está alojado en Railway. Se configuraron políticas estrictas de CORS y cookies (`SameSite: none`, `Secure`) para asegurar la comunicación cross-site (Netlify ↔ Railway).

3. Base de Datos

Almacenamiento NoSQL gestionado en la nube usando MongoDB Atlas. El servidor de Railway se conecta a este clúster mediante una cadena de conexión URI segura inyectada como variable de entorno.
